1. What are the different types of missing data?
Missing data can be Missing Completely At Random (MCAR), Missing At Random (MAR), or Missing Not At Random (MNAR). These differ in whether missingness depends on other variables or the missing values themselves.

2. How do you handle categorical variables?
Categorical variables can be handled using label encoding (assigns numbers 0,1,2...), one-hot encoding (creates binary columns), or ordinal encoding (for ordered categories). Choice depends on the algorithm and variable nature.

3. What is the difference between normalization and standardization?
Normalization scales data to a range [0,1] using min-max formula, while standardization scales to mean=0 and std=1 using z-score. Use normalization for bounded ranges, standardization for algorithms sensitive to variance.

4. How do you detect outliers?
Common methods include IQR method (values beyond Q1-1.5*IQR and Q3+1.5*IQR), z-score method (|z|>3), and visualization using boxplots or scatter plots. Statistical tests can also identify extreme values.

5. Why is preprocessing important in ML?
Preprocessing improves model accuracy, reduces noise, handles missing values, and ensures consistent data scales. Clean, properly formatted data leads to better model performance and faster training.

6. What is one-hot encoding vs label encoding?
Label encoding converts categories to integers (0,1,2...) and works well for tree models, while one-hot encoding creates binary columns for each category and suits linear models. Use one-hot for algorithms that treat values as continuous.

7. How do you handle data imbalance?
Methods include oversampling minority class, undersampling majority class, SMOTE, class weights, stratified sampling, or using appropriate metrics (F1-score, precision-recall). Choice depends on dataset size and problem domain.

8. Can preprocessing affect model accuracy?
Yes, preprocessing significantly affects accuracy—proper handling of missing values, outliers, and feature scaling improves model performance. Poor preprocessing can introduce bias, noise, or lose important information affecting predictions.
